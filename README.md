# 🎓 Estudio de Ciberseguridad

Bitácora y código propio de mi transición hacia la ciberseguridad. Todo lo que hay acá lo escribí y entendí yo mismo — es progreso real, no perfecto, pero honesto.

## Sobre este repo

- Parto desde una base básica: conceptos de redes (IP, VPN, TCP/UDP), pero sin experiencia previa en terminal
- Voy documentando cada avance, aunque sea pequeño
- El objetivo no es impresionar, sino mostrar una curva de aprendizaje real

## Contenido

| Carpeta/Archivo | Descripción |
|---|---|
| `/scripts` | Scripts de automatización en Linux (bash) — módulo de scripting |
| `/notas` | Apuntes por tema a medida que avanzo |
| `/labs` | Write-ups de laboratorios básicos practicados en Kali Linux |
